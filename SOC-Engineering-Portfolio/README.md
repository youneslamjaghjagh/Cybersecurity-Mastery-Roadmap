# SOC Engineering Portfolio

Hands-on practice in SOC engineering, telemetry pipelines, Sigma detection engineering, SIEM dashboards, and digital forensics and incident response (DFIR).

Based on the [SOC Engineering Portfolio project](https://linear.app/younes-lamjaghjagh/project/soc-engineering-portfolio-68eba5c4de1b).

## Learning sequence

1. **Cyber range:** document an isolated lab, its architecture, and safe testing boundaries.
2. **Telemetry:** collect sample logs, explain their fields, and verify ingestion.
3. **Detections:** write Sigma rules and record test events, expected matches, and false positives.
4. **SIEM dashboards:** build views that help investigate the collected events.
5. **Incident response:** practice triage and write a timeline, findings, and response recommendations.

## Practice loop

Choose one small objective → build it in the lab → test it → explain the result in your own words → repeat without the guide.

For each exercise, save:

- Objective and prerequisites
- Reproducible steps and configurations
- Sanitized sample events or screenshots
- Expected versus actual results
- Lessons learned and the next improvement

## Safety

Use only systems you own or are authorized to test. Never commit credentials, private logs, personal data, or live malware. Keep evidence sanitized.
